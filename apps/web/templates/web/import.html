BATCH GUIDELINES

Fast and reliable intake.

Follow these standards to ensure flawless parsing, zero duplicates, and fair caller workload distribution.

Paste Phone Numbers

Paste 10-digit Indian numbers in any standard format:

9392130350 +91 6304569634 9179897 73522 63041 53694
  • Braces { ... } or empty lines are ignored.
  • Duplicate phone numbers are imported as separate leads.
  • New leads start as Pending with blank names.

Spreadsheet Upload

Supported column headers for CSV or XLSX workbooks:

Required phone mobile
Optional name email location college neet_status pcb_percentage notes

Accepted formats: .csv or .xlsx up to 5 MB.

Smart Workload Balancing

Caller dropdown displays current pending leads for each caller. Callers with fewer pending calls are placed at the top so you can balance calls evenly and eliminate delays.
