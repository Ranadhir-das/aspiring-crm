Fast and reliable intake.

Paste Phone Numbers:

Paste 10-digit Indian numbers (e.g. 9392130350, +91 6304569634, 9179897 73522, 63041 53694). Braces { ... } or empty lines are ignored. Duplicates are accepted as separate leads with blank names.

Spreadsheet Upload:
